                📘 راهنمای جامع مشخصات فنی API درگاه پیامک (نسخه ۱.۰)

۱. اطلاعات پایه سرویس (Endpoint Specifications)

            

                

                    
                        

                            پارامتر
                            مقدار استاندارد
                            توضیحات
                        

                    
                    
                        

                            Base URL
                            https://api.sms-gateway.example.com
                            آدرس پایه سرور جهت فراخوانی تمام متدها
                        

                        

                            Endpoint
                            POST /api/v1/sms/send
                            آدرس سرویس ارسال تکی پیامک
                        

                        

                            Content-Type
                            application/json
                            فرمت داده‌های ارسالی به صورت JSON می‌باشد (اجباری)
                        

                        

                            Accept-Language
                            fa یا en
                            زبان متن پیام بازگشتی در فیلد message (اختیاری)
                        

                        

                            Authorization
                            Bearer {API_KEY}
                            کلید احراز هویت سرویس (اجباری - در صورت فقدان خطای ۴۰۱ بازمی‌گردد)

۳. جدول کدهای وضعیت رایج (Status Codes & Error Mapping)

            

                

                    
                        

                            کد منطقی (code)
                            کد HTTP
                            توضیح فارسی
                            اقدام پیشنهادی
                        

                    
                    
                        

                            SENT_OK
                            200
                            پیام با موفقیت ارسال شد.
                            درخواست به درستی ثبت و ارسال شده است.
                        

                        

                            INVALID_NUMBER
                            400
                            شماره مقصد نامعتبر است.
                            شماره را اصلاح کنید (باید ۱۱ رقمی با فرمت 09 باشد).
                        

                        

                            EMPTY_MESSAGE
                            400
                            پیامک خالی است.
                            فیلد message نباید رشته خالی باشد.
                        

                        

                            UNAUTHORIZED
                            401
                            کلید API نامعتبر است.
                            مقدار API Key را در تب تنظیمات بررسی نمایید.
                        

                        

                            RATE_LIMIT_EXCEEDED
                            429
                            تعداد درخواست‌ها بیش از حد مجاز است.
                            نرخ ارسال پیامک‌ها در هر ثانیه/دقیقه را کاهش دهید.
                        

                        

                            SERVER_ERROR
                            500
                            خطای داخلی سرور پیامک.
                            با پشتیبانی فنی ارائه‌دهنده سرویس پیامک تماس بگیرید.
