# 📡 سامانه مینی‌اپلیکیشن تست و عیب‌یابی اتصال به سرور پیامک (SMS Gateway Tester)

این مینی‌اپلیکیشن یک ابزار **کاملاً مستقل، سبک و ایزوله** (بدون هیچ‌گونه وابستگی به سرویس اصلی `relay_service`) است که اختصاصاً جهت بررسی، عیب‌یابی شبکه، تست احراز هویت و ارزیابی صحت ارسال پیامک بر اساس **داکیومنت و مشخصات فنی رسمی سرور پیامک (نسخه ۱.۰)** توسعه داده شده است.

---

## 🌟 ۱. ویژگی‌ها و قابلیت‌های مینی‌اپلیکیشن

1. **انطباق ۱۰۰٪ با مستندات رسمی:**
   - متد: `POST`
   - آدرس پایه: `https://api.sms-gateway.example.com`
   - اندپوینت: `/api/v1/sms/send`
   - هدرهای استاندارد: `Authorization: Bearer {API_KEY}`، `Content-Type: application/json`، `Accept-Language: fa|en`
   - بدنه درخواست: `{"destination": "09121234567", "message": "متن پیامک"}`
   - تفسیر و ترجمه تمام کدهای پاسخ: `SENT_OK` (200), `INVALID_NUMBER` (400), `EMPTY_MESSAGE` (400), `UNAUTHORIZED` (401), `RATE_LIMIT_EXCEEDED` (429), `SERVER_ERROR` (500).

2. **عیب‌یابی گام‌به‌گام شبکه و زیرساخت (4-Step Deep Diagnostics):**
   - **مرحله ۱ (DNS):** بررسی تبدیل موفق نام دامنه `api.sms-gateway.example.com` به آی‌پی در شبکه شما و محاسبه زمان پاسخ.
   - **مرحله ۲ (TCP Port):** بررسی باز بودن پورت شبکه (پورت ۴۴۳ برای HTTPS یا ۸۰ برای HTTP) و عدم انسداد توسط فایروال.
   - **مرحله ۳ (SSL/TLS):** تست نشست امنیتی، بررسی اعتبار گواهی SSL، تاریخ انقضا و الگوریتم رمزنگاری.
   - **مرحله ۴ (HTTP Web Layer):** ارسال درخواست Probe به وب‌سرور و بررسی کدهای وضعیت لایه وب.

3. **مدیریت زنده کانفیگ و تنظیمات (Visual & JSON Configuration):**
   - امکان تغییر تمام پارامترها (Base URL، Endpoint، API Key، زبان، تایم‌اوت، اعتبارسنجی SSL) مستقیماً از داخل پنل وب یا فایل `config.json`.
   - ذخیره آنی تنظیمات بدون نیاز به راه‌اندازی مجدد.
   - دکمه بازنشانی به مقادیر پیش‌فرض داکیومنت رسمی با یک کلیک.

4. **تست ارسال پیامک آزمایشی:**
   - شمارشگر زنده تعداد کاراکتر (تا سقف ۴۸۰ کاراکتر طبق داکیومنت) و تخمین تعداد بخش‌های پیامک (SMS Parts).
   - قالب‌های آماده تستی (تست سلامت، هشدار مانیتورینگ، کد اعتبارسنجی).
   - نمایش کامل جزئیات فنی: زمان تأخیر بر حسب میلی‌ثانیه، کد HTTP، هدرها، بدنه ارسالی و پاسخ خام JSON به همراه راهنمای رفع مشکل.

5. **شبیه‌ساز آفلاین بدون نیاز به اتصال شبکه (Mock Simulator Mode):**
   - امکان تست کامل سناریوها حتی در زمان قطعی اینترنت یا در محیط ایزوله.
   - شبیه‌سازی سناریوهای موفق، شماره نامعتبر، پیام خالی، خطای کلید ۴۰۱، لیمیت ۴۲۹ و خطای سرور ۵۰۰.

6. **تاریخچه تست‌ها (Audit & History):**
   - ذخیره سوابق تست‌ها در فایل محلی `data/history.json`.
   - امکان بررسی و بازبینی مجدد تمام بسته‌های ارسالی و دریافتی.

7. **دو روش استفاده:**
   - داشبورد تعاملی تحت وب (پورت ۸۰۸۰).
   - ابزار سریع تحت خط فرمان (CLI) بدون نیاز به مرورگر.

## 🚀 ۲. نحوه اجرا و استفاده

### روش اول: اجرای داشبورد تحت وب (پیشنهادی)
کافیست روی فایل زیر دابل‌کلیک کنید:
```bat
run.bat
```
یا در خط فرمان دستور زیر را اجرا نمایید:
```bash
python app.py
```
1. پنجره مرورگر شما به صورت خودکار در آدرس زیر باز می‌شود:
   **`http://127.0.0.1:8080`**
2. تمام زبانه‌ها شامل تست ارسال، عیب‌یابی شبکه، تغییر کانفیگ و تاریخچه در دسترس شماست.

---

### روش دوم: اجرای سریع از طریق ترمینال (CLI)
اگر قصد دارید به سرعت از داخل PowerShell یا CMD وضعیت را بسنجید:

- **بررسی سلامت و عیب‌یابی ۴ مرحله‌ای شبکه:**
  ```bash
  python test_cli.py --diagnose
  ```
- **ارسال پیامک تستی به یک شماره مشخص:**
  ```bash
  python test_cli.py --send 09121234567 -m "این یک تست اتصال است"
  ```
- **مشاهده کانفیگ فعلی:**
  ```bash
  python test_cli.py --info
  ```
- **فعال‌سازی یا غیرفعال‌سازی حالت شبیه‌ساز (Mock):**
  ```bash
  python test_cli.py --mock on
  python test_cli.py --mock off
  ```

## 📋 ۴. مشخصات فنی استاندارد API (مرجع داکیومنت درگاه پیامک)

| پارامتر | مقدار | وضعیت | توضیحات |
|---|---|---|---|
| **Base URL** | `https://api.sms-gateway.example.com` | الزامی | آدرس پایه سرور پیامک |
| **Endpoint** | `/api/v1/sms/send` | الزامی | مسیر سرویس ارسال تکی پیامک |
| **Method** | `POST` | الزامی | روش ارسال متد HTTP |
| **Content-Type** | `application/json` | الزامی | نوع داده ارسالی |
| **Accept-Language** | `fa` یا `en` | اختیاری | زبان پیام‌های خروجی |
| **Authorization** | `Bearer {API_KEY}` | الزامی | کلید احراز هویت سرویس |
| **destination** | `09121234567` | الزامی | شماره تلفن همراه مقصد (۱۱ رقم) |
| **message** | متن پیامک | الزامی | حداکثر ۴۸۰ کاراکتر |

## 💡 ۵. راهنمای خطایابی سریع (Troubleshooting)

- **خطای پورت یا تایم‌اوت (TCP Timeout / Connection Refused):**
  اگر در تب عیب‌یابی مرحله ۲ خطا داد، ارتباط سرور شما با هاست مقصد مسدود است. باید از ادمین شبکه بخواهید خروجی پورت ۴۴۳ به مقصد آی‌پی `192.0.2.1` (دامنه `api.sms-gateway.example.com`) را در فایروال مجاز کند.
- **خطای SSL (SSLCertVerificationError):**
  اگر در محیط ایزوله یا پراکسی شرکتی هستید و گواهی SSL بازرسی می‌شود، در تب تنظیمات گزینه **Verify SSL** را خاموش کرده و تنظیمات را ذخیره نمایید.
- **خطای ۴۰۱ (UNAUTHORIZED):**
  مقدار `api_key` را در تب تنظیمات با کلید معتبری که شرکت به شما داده است جایگزین نمایید.
